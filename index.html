MOSAIC

Multi-ROI Optical System for Analysis of Intracellular Calcium

버전 0.1.0 · 원본 앱 기준

Version 0.1.0 · original app

MOSAIC은 Nikon ND2 형식의 고속 형광 영상에서 심근세포의 Ca²⁺ 전이(transient)를 분석하는 데스크톱 프로그램입니다. 한 시야 안의 여러 세포 또는 세포 내 영역에 ROI를 설정하고, 박동마다 진폭, time to peak, 최대 상승 속도, 10·50·90% 감쇠 시간을 계산하여 Excel 파일로 저장합니다. Windows와 macOS에서 동작하며 Python 3.9 이상이 필요합니다.

MOSAIC is a desktop program for analyzing cardiomyocyte Ca²⁺ transients in high-speed Nikon ND2 fluorescence recordings. ROIs are set on several cells or subcellular regions of one field of view, and for each beat the program calculates amplitude, time to peak, maximum rising rate, and 10/50/90% decay times, which are saved as Excel files. It runs on Windows and macOS and requires Python 3.9 or later.

3설치 요약Installation in brief

  1. python.org에서 Python 3.9 이상을 설치합니다. Windows에서는 Add python.exe to PATH를 선택합니다.
  2. MOSAIC ZIP 파일을 로컬 폴더(예: C:\MOSAIC)에 압축 해제합니다. Dropbox, OneDrive 등 동기화 폴더는 사용하지 않습니다.
  3. run_app.bat(Windows) 또는 run_app.command(macOS)를 실행합니다. 첫 실행 시 필요한 패키지가 설치되며 수 분이 걸립니다.
  4. 설명서 3장 예제로 따라하기에 따라 예제 파일을 분석합니다.
  1. Install Python 3.9 or later from python.org. On Windows, select Add python.exe to PATH.
  2. Extract the MOSAIC ZIP to a local folder such as C:\MOSAIC. Do not use synced folders such as Dropbox or OneDrive.
  3. Run run_app.bat (Windows) or run_app.command (macOS). The first launch installs the required packages and takes several minutes.
  4. Analyze the example file following chapter 3, Example walkthrough.

4사용 전 유의사항Before use

원본 v0.1.0의 Pacing interval 기본값은 500 ms입니다. 설명서의 2 Hz 예제는 기존 앱에서 450 ms를 수동 입력한 결과를 보여 줍니다. 앱 기본값이 이미 변경되었다는 뜻은 아닙니다. 분석 시 실제 파형과 검출 이벤트를 확인하십시오. 자세한 내용은 설명서 7장 알려진 제약을 참조하십시오.

The original v0.1.0 has a default Pacing interval of 500 ms. The 2 Hz example in the guide uses a manually entered value of 450 ms in the unchanged app. This does not mean the app default has been changed. Inspect waveforms and detected events for each analysis. See chapter 7, Known limitations.
