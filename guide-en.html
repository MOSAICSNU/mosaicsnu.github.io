MOSAIC User Guide

This guide describes the installation of MOSAIC version 0.2.0, a complete analysis of the example recording, and every control and setting.

MOSAIC (Multi-ROI Optical System for Analysis of Intracellular Calcium) analyzes cardiomyocyte Ca²⁺ transients in high-speed Nikon ND2 fluorescence recordings. You place ROIs over cells or parts of cells in one field of view; MOSAIC detects the calcium signal of each beat and reports amplitude, time to peak, maximum rising rate, and decay times.

Organization of this guide
  • New users: follow 1. Install and then 3. Example walkthrough in order. It takes about 20 minutes.
  • Looking for one button: find its number in 4. Button reference.
  • Before analyzing your own data, read 5. Choosing settings and 7. Known limitations.

What you need

  • A Windows 10/11 or macOS computer. RAM of at least twice the ND2 file size is recommended (the example file is 0.3 GB, so most computers are fine).
  • An internet connection. Required components are downloaded automatically on first launch.
  • The MOSAIC program (ZIP) from the home page, and the example file MOSAIC_example_2Hz.nd2 (available upon request; see Downloads)
  • A working folder on a local disk. Avoid Dropbox, OneDrive, iCloud, and Google Drive folders.

1Install and launch

Installation is needed once per computer. Afterwards you start MOSAIC by double-clicking one file.

1.1Install Python

MOSAIC is written in Python and needs Python 3.10 or later. Skip this if it is already installed.

  1. At python.org/downloads, click Download Python.
  2. Run the installer.
  3. Windows: tick Add python.exe to PATH at the bottom of the first screen, then click Install Now.
  4. macOS: follow the installer to the end.
Common mistake

If Add python.exe to PATH is not ticked on Windows, MOSAIC cannot find Python. Run the Python installer again and choose Modify to enable it, or uninstall and reinstall.

1.2Get MOSAIC

  1. From Downloads, get MOSAIC v0.2.0 (ZIP).
  2. Right-click the ZIP → Extract All to a local folder, for example C:\MOSAIC.
  3. Request MOSAIC_example_2Hz.nd2 as described on the same page, and keep the file somewhere easy to find, such as C:\MOSAIC-data.
Why synced folders should be avoided

The first launch installs several hundred MB of components. If a sync client locks those files to upload them, installation stops with WinError 32. Results (_ana folder) are also written next to the ND2 file, so keep ND2 files in a writable local location too.

1.3Launch

SystemHow to launch
WindowsDouble-click run_app.bat in the MOSAIC folder. If "Windows protected your PC" appears, click More info → Run anyway.
macOSDouble-click run_app.command. If blocked, right-click → Open. If that fails, run chmod +x run_app.command once in Terminal.

The first launch shows Creating Python virtual environment... and Installing Python packages... in a console window and takes several minutes; then the MOSAIC window opens. Later launches take a few seconds.

3Example walkthrough

Analyze one cell in MOSAIC_example_2Hz.nd2 from start to finish.

Example file
ContentFluorescence calcium recording of adult cardiomyocytes under 2 Hz field stimulation (cropped from an original recording)
Size288 × 240 px · 8-bit · 4,000 frames
Interval / duration2.01 ms (≈ 500 frames/s) · 8.04 s
File size295 MB

3.1Open the ND2 file

  1. Click Open ND2 in Controls.
  2. Select MOSAIC_example_2Hz.nd2 and click Open.
Check
  • Status: Loaded ND2 | dtype=uint8 | sizes={'T': 4000, 'Y': 240, 'X': 288} …
  • Playback: Frame: 1 / 4000 | Time: 0.000000 s
  • The graph time axis runs from 0 to 8 s.

Tip: Play plays the movie in real time; the horizontal cell in the middle brightens with every beat. Click again to stop.

3.2Place the background ROI

To remove camera noise and background brightness, place a background ROI where there are no cells.

  1. Click Add Background. A blue circle appears in the center.
  2. Drag the inside of the circle to the dark empty area at the lower right.
  3. Drag the small handle on the circle's edge to shrink it so it does not touch a cell.

Alternative: Recommend Background finds the darkest area over the first 10 s automatically. The search is random, so the position can change each time; check by eye that no cell is inside.

3.3Place an ROI over the cell

  1. In the ROI group, set Shape to Rectangle; rectangles fit rod-shaped cells well.
  2. Click Add ROI. A yellow rectangle appears in the center.
  3. Drag the inside of the rectangle onto the horizontal cell.
  4. Use the ◇ handle (lower right) to resize and the ○ handle (right middle) to rotate until it sits just inside the cell outline.
Placing an ROI
  • Slightly inside the cell border. Crossing the border mixes in background and lowers the amplitude.
  • Not overlapping neighboring cells.
  • To analyze part of a cell (for example one end), place a small ROI over that part only.

Optional (op) Auto ROI: replaces the last ROI by a polygon enclosing the pixels that change most during the first 3 s. If you do not like it, click the same button ((op) Undo Auto ROI) to restore the original.

3.4Calculate the trace

  1. Click Calculate.
Check
  • About 16 regular peaks in the upper graph (8 s × 2 Hz).
  • Status includes Background: set and Graph: background-corrected intensity.

The first click loads the whole movie into memory, so the window may pause briefly. After moving or resizing an ROI, always click Calculate again to update its trace.

3.5Set the analysis range (Tran.)

The orange band in the upper graph is the time range searched for transients. It initially covers the first 25% of the recording.

  1. Drag the right edge of the band almost to the end, or type Start 0.2 and End 7.8 in Ranges → Tran.
  2. Zoom into the lower detail graph with the mouse wheel to look at the peak shapes. Detail view X (for example 1–3 s) sets an exact range.
Choosing the range
  • Include only stable pacing. Leave out unstable beats right after stimulation starts and any movement or noise.
  • Leave at least one Pacing interval after the last peak so that it can be analyzed.

3.6Check Pacing interval first

In Transient analysis, check that Pacing interval is 450 ms. This is the default for 2-Hz pacing, so the example needs no change. For other pacing rates, see 5. Choosing settings.

Set it before photobleaching

Photobleaching correction also uses this value to locate beats, so set it before photobleaching correction.

3.7Photobleaching correction (optional)

Under continuous illumination the fluorescence slowly fades and the baseline drifts down. Correct it when the baseline looks tilted.

  1. Click Cal. Photobleaching in Controls.
  2. Look at the yellow dashed line (fitted baseline) and the red points (samples used as baseline).
  3. If the red points lie only on the flat bottom, not on peaks, click Confirm Photobleaching.
Check
  • Preview Status: Photobleaching preview calculated (ratio=1). Press Confirm Photobleaching to apply.
  • After applying: Photobleaching correction confirmed and applied.

Red points on top of peaks mean those beats were not detected. Check Pacing interval and Peak cutoff, then click Cal. Photobleaching again. To undo, click Reset Photobleaching.

3.8Calculate transients

  1. Click Calculate transients at the top of Transient analysis.
Check
  • Status: One average transient calculated from 14/14 selected events across 1 ROI trace(s). Pacing interval = 450 ms.
  • The number detected (14) should be close to the number of beats in the 7.6-s range (about 15).
  • Average graph: a steep rise at 0 ms, a peak near 30 ms, then a slower decay.

3.9Review the events

Each row of the event table is one beat. Scroll the table to the right for the decay columns.

  • Untick Use to remove a beat from the average and summary; the average graph redraws immediately.
  • Good reasons to exclude: two overlapping peaks, a spike caused by movement, or a clearly different shape.
  • Use the event time (Ab_start) to zoom to that beat in the detail graph.

Column meanings are in Button reference – event table.

3.10Save the ROI

  1. Click Save ROI in Controls.
Check: expected values for the example (v0.2.0)

Values vary slightly with ROI position.

Tran NTran Amp dF/F0Tran Peak msTran Max d(F/F0)/dtDecay 10% msDecay 50% msDecay 90% ms
14≈ 1.47≈ 28.6≈ 74≈ 23.6≈ 61.5≈ 133.5

The workspace is cleared after saving. To analyze another cell, repeat from step 3 (Add ROI). The background ROI and analysis range are kept.

3.11Export the results

  1. Click Save in Controls.

A folder MOSAIC_example_2Hz_ana is created next to the ND2 file with five files. Their contents are described in 6. Reading the output files.

Check

Status: Saved 1 checked ROI(s) to …\MOSAIC_example_2Hz_ana.

Saved ROIs with Use unticked are not exported. Clicking Save again for the same file overwrites the previous results.

3.12Reload the analysis

  1. Next time, start MOSAIC and click Load Info.
  2. Select MOSAIC_example_2Hz_ana\analysis_info.json.
  3. The ND2 file reopens with the saved ROIs and background ROI. Click a row in the Saved ROI table to show that ROI's analysis.
Note

The JSON stores the path of the ND2 file. If the ND2 file has been moved, MOSAIC looks next to the results folder and otherwise asks you to select the original file. Results are restored as saved, not recalculated.

This completes the analysis procedure. Analyze your own recordings in the same order.

5Choosing settings

What to decide for your own data, in order.

OrderSettingRecommendationHow to check
1Background ROINo cells or debris, not in the dark image corner shadow; as large as possiblePlay the movie and make sure nothing passes through
2Cell ROISlightly inside the cell border, not overlapping neighborsThe cell stays inside the ROI across frames
3Tran. rangeStable pacing only, with at least one Pacing interval after the last beatCount the peaks in the range

When reporting

In papers and reports, state the Pacing interval, Peak cutoff, Before start, whether photobleaching correction was applied, and the MOSAIC version (v0.2.0).

7Known limitations (v0.2.0)

These behaviors of the current version are documented so that results can be interpreted correctly. Changes between versions are listed in the release notes.

Limitation 1

Detection criteria and the number of detected beats

MOSAIC detects paced transients. A beat is accepted only if it has a stable baseline before the rise, an amplitude above Peak cutoff, a return below 25% of its amplitude for 30 ms, and a rise shorter than its recovery. Slow or abnormal events can be rejected, and a beat is not measured without one Pacing interval of recording after its peak. Photobleaching correction uses the same detection, so missed beats can be included among the baseline points (red points).

  • Always compare Tran N with the expected number of beats in the range.
  • Set Pacing interval before Cal. Photobleaching.
  • Record and report the settings used for each analysis.
#LimitationDetails and what to do
2MemoryThe first Calculate loads the whole movie. Required ≈ frames × height × width × bytes per pixel (e.g. 12,406 frames of 600 × 600 8-bit ≈ 4.5 GB). With too little RAM the program becomes very slow or closes.
3Display range8-bit images are shown at 0–255; images above 8 bits use contrast limits from the first frame. Display settings never change measured values.
4ND2 structureSingle-channel time-lapse (T × Y × X) only. Multi-channel, Z-stack, and multi-position files are rejected when opened.
5Fixed internal settingsSmoothing window 20 ms, onset = 10% of amplitude, recovery = below 25% of amplitude for 30 ms. Measurements use the smoothed trace, so very fast upstrokes can show a slightly longer time to peak.
6Fixed ROIsROIs do not follow cell contraction or movement. Manual ROI placement can affect results.
7Features not in the interfaceThe code contains caffeine-induced (SR) Ca²⁺ release analysis, but v0.2.0 has no buttons for it.
8Not respondingDuring movie loading, Auto ROI, and Recommend Background the window appears frozen. Wait for Status to change.

9Glossary

ND2
Image file saved by Nikon NIS-Elements; it contains the frames and their acquisition times.
ROI
Region of interest: the area whose brightness is measured, such as one cell.
Background ROI
A cell-free area used to subtract camera noise and background brightness.
Trace
Mean brightness inside an ROI plotted over time.
Ca²⁺ transient
One waveform per beat: calcium fluorescence rises quickly and decays more slowly.
F₀, F/F₀
F₀ = reference brightness just before a beat (mean over Before start). F/F₀ = brightness ÷ F₀, which makes cells of different brightness comparable.
Onset
Start of a beat: the time the rise reaches 10% of the amplitude.
Time to peak
Time from onset to peak.
Decay X%
Time after the peak until the amplitude has decreased by X%. Decay 50% is the half-decay time.
Photobleaching
Gradual loss of fluorescence under continuous illumination.
Pacing interval
MOSAIC setting derived from the time between electrical stimuli; it sets the beat spacing and the analysis window (2 Hz → 450 ms).
Prominence / Peak cutoff
How far a peak rises above its surroundings. Peak cutoff sets the threshold as a multiple of the noise.
